# Grand Stay Hotel & Resort - Management System

A complete hotel website and front-desk console.

**Guest website:** home page with Plan Your Stay (live availability), online reservation, rooms & suites,
facilities, gallery and guest reviews.

**Staff portal:** dashboard with live statistics and charts, rooms & housekeeping, guest registry with search,
reservations (check-in, check-out, cancel), service charges, payments, GST invoices and CSV reports.

Demo staff login: `admin` / `Hotel@123`

## Deployment
1. Upload every file to the root of a GitHub repository (no sub-folders).
2. On share.streamlit.io choose the repository, branch `main` and main file `app.py`.
3. Deploy.
